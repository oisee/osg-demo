# Приложение C. Ограничения и глоссарий

## Чего эта демонстрация не обещает

- **Локальная система, реальная семантика там, где она измерена.** open-steamgate выполняет ABAP,
  транспилированный в JavaScript. Там, где поведение измерено в реальной системе
  (A4H), книга об этом говорит; там, где нет, книга говорит и об этом.
- **Фоновые задания** выполняются только с `STG_DB=file` (SQLite в файле), а
  worker (процесс, который выполняет задания) - это отдельный процесс (`node tools/osd-batch-runs.mjs worker`).
- **Планирование, а не exactly-once.** Перезапуск или повторный импорт не
  запускает задание дважды, но сбой после бизнес-фиксации шага и до записи
  его результата оставляет задание в состоянии `RUNNING` для оператора.
- **Цепочка заданий** следует документированному SAP шаблону событий, но измерена
  только на open-steamgate.
- **Только локальные объекты** не входят в zip abapGit: `ZCL_OSD_FLEET_TRAN` и
  транзакция `ZOSD_FLEET` (интерфейс движка), `ZCL_OSD_FLEET_TPL` (нужны
  `ZCL_OSD_TPL` и `ZCL_AJSON`), `ZCL_OSD_FLEET_DOCTOR` («доктор» заданий движка).
- **Начальные строки (seed) не переносятся.** Система получает пустые таблицы.
- **UI5** загружается с `ui5.sap.com`; браузеру нужен доступ к нему.
- **Таблица журнала приложения** - демонстрационное представление журнала флота, а не SLG1.

## Глоссарий

| Термин | Значение в этой книге |
|---|---|
| OSD | open-steamgate: локальная система ABAP в VS Code |
| pack (пак) | папка с `osd-pack.json`, накладываемая поверх системы; этот репозиторий - один из них |
| classrun | `IF_OO_ADT_CLASSRUN~MAIN` класса, запускаемый по F9 |
| WEBGUI | локальный SAP GUI для HTML; `ZGUI_<report>` запускает преобразованный классический отчет |
| BAL | журнал приложения (`CL_BALI_*`), объект `ZOSD_FLEET`, подобъект `AUDIT` |
| run ID | UUID (с суффиксом, например `-VOY`, `-READY` или `-OK1`), записанный как внешний ID журнала BAL; связывает задания и журналы |
| worker (процесс-обработчик) | процесс, который выполняет шаги заданий из очереди (`tools/osd-batch-runs.mjs`) |
| job doctor («доктор» заданий) | `ZCL_OSD_JOB_DOCTOR` из open-steamgate: состояние задания, ожидание, шаги и технический журнал |
| L0 / L1 / L2 | текст шаблона / типизированная модель генерации / предметные правила (глава 10) |
| trace (трассировка) | для каждой сгенерированной строки: строка шаблона, путь в модели, узел модели, строка правила |
| lift | переписывание известной формы кода в лучшую по модели, вместе с ее обязательствами |
| recipe (рецепт) | шаблон плюс способ построения его модели (`recipes/` в open-steamgate) |
| A4H | система разработчика SAP, на которой проводились измерения |
