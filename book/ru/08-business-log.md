# 8. Журнал приложения

Аудит флота считает корабли и рейсы и сообщает, совпадают ли они с
ожидаемыми значениями. В этой главе результат сохраняется так, как это делает
журнал приложения SAP (BAL): `CL_BALI_*` записывает журнал для каждого запуска
в объект `ZOSD_FLEET`, подобъект `AUDIT`, с сообщениями, их важностью и
временем UTC, и журнал сохраняется после перезапуска.
Для этого нужно персистентное подмножество BAL из
[open-steamgate PR #207](https://github.com/oisee/open-steamgate/pull/207)
(в текущей ветке `main` оно есть; установленный VSIX должен его включать).

1. В системе с начальными строками (seed) откройте [ZCL_OSD_FLEET_BAL](../../src/zcl_osd_fleet_bal.clas.abap)
   и нажмите **F9**. Класс записывает два успешных аудита и одну намеренную
   ошибку, фиксирует их и выводит один batch ID и три разных дескриптора журнала.
2. Откройте [ZCL_OSD_FLEET_BAL_VIEW](../../src/zcl_osd_fleet_bal_view.clas.abap) и
   нажмите **F9**. Найдите три run ID, оканчивающиеся на `OK1`, `OK2` и `ERR`. В каждом есть
   `started`, `Observed 6 ships and 20 voyages`, затем сообщение об успехе или ошибке;
   в `ERR` одна ошибка. Перезапустите OSD с тем же файлом базы данных и снова
   запустите просмотр: те же журналы и те же метки времени UTC сообщений на месте. `RENDER` также
   принимает точный run ID, `IV_SEVERITY` или `IV_ERRORS_ONLY` для чтения с фильтром.
3. Посмотрите те же сообщения в виде таблицы: введите `ZGUI_OSD_FLEET_BALV` в
   **WEBGUI** (или откройте
   `http://localhost:8099/sap/bc/gui/sap/its/webgui/?okcode=ZGUI_OSD_FLEET_BALV`).
   [ZOSD_FLEET_BALV](../../src/zosd_fleet_balv.prog.abap) показывает по одной строке на сообщение
   с полями `RUN_ID`, `ITEM`, `SEVERITY`, `TEXT` и `UTC`; строки отсортированы по запуску и
   номеру сообщения; строки поставляет `ZCL_OSD_FLEET_BAL_VIEW=>MESSAGES`. Это
   демонстрационное представление журнала флота, а не SLG1. Если журнала еще нет, выводится
   `No fleet business log to show` (в open-steamgate за этим следует причина
   от BAL, поскольку чтение вызывает исключение, если ни один журнал не подходит).
4. Запустите `ZCL_OSD_FLEET_BAL` в Testing. Его тест ABAP Unit, который пишет в БД, помечен как
   `DANGEROUS`: он проверяет фильтр ошибок и порядок сообщений. OSD дает
   тестам на SQLite/DuckDB одноразовую базу данных; для HANA/Postgres выберите
   отдельную схему/базу данных. Его очистка на A4H не тестировалась.
   `SLICE_SKIP_UI=1 OSD_HOME=/path/to/open-steamgate
   node test/slice.mjs` запускает более широкую проверку пака (pack) на этой среде выполнения.
