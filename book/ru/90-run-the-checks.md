# Приложение A. Запуск проверок

В checkout open-steamgate один раз выполните `npm ci && npm run bootstrap` (bootstrap собирает и подключает транспайлер, закрепленный в checkout). Затем `OSD_HOME=/path/to/open-steamgate node test/slice.mjs` собирает этот checkout движка с данной папкой в качестве пака (pack), запускает его на свободном порту и проверяет флот дирижаблей от начала до конца: шесть кораблей в `ShipSet`, classrun отчета по флоту, `$filter` по статусу, MERGE с последующим чтением, плитку панели запуска, открывающую отчет-список (для этой проверки нужен браузер с доступом к ui5.sap.com; `SLICE_SKIP_UI=1` пропускает ее и сообщает об этом, `SLICE_CHROMIUM=<path>` выбирает браузер), и тест ABAP Unit отчета. Скрипт останавливает запущенный им движок и завершается с ненулевым кодом, если какая-либо проверка не прошла. `OSD_HOME=/path/to/open-steamgate node test/jobs.mjs` так же проверяет фоновые задания на временном файле SQLite: одно задание с его журналом BAL и обе цепочки (успешная завершается, неуспешная оставляет задание готовности в ожидании).

`OSD_HOME=/path/to/open-steamgate node test/lift.mjs` проверяет, что сгенерированная
область `ZCL_OSD_FLEET_LIFT=>AFTER` совпадает с тем, что рецепт lift формирует из
`BEFORE` (глава 11); `--write` генерирует ее заново. Этот скрипт также запускает проверка 16 в slice.

`OSD_HOME` может быть и checkout'ом с установленной системой (глава 22,
`tools/fleet-system.mjs --install`). Тогда `test/slice.mjs` и `test/rap.mjs`
не выставляют `OSD_PACKS`, от которого такой checkout отказывается: флот — это
слой `osg-demo` системы, и первая строка называет его дайджест.
